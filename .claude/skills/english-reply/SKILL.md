# English Reply

## Style

- Be concise, warm, and direct.
- State what changed, what was checked, and what remains uncertain.
- Avoid over-promising.
- Preserve the owner's authorship and intent.
- Do not publish or submit the reply unless explicitly requested.

## Useful Shape

```markdown
Thanks for the report. I updated ...

Checked:
- ...

One note: ...
```

## Pipeline

Pull requests in this repository are written in Japanese, not in this voice — see [publish-pr](../publish-pr/SKILL.md). Use this skill for replies on other people's repositories and external collaboration.
