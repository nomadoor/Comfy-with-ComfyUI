# ADR: mediaRow をステップカードにする (2026-09-29)

## Status
Accepted（`2026-01-14-media-inline-group-borders.md` を置き換える）

## Context
- `mediaRow` は画像を左、本文を右に並べ、上下に 1px の線を引く一覧だった。記事の本文と同じ強さで縦に長く並ぶため、workflow だけ欲しい読者が次の workflow まで飛ばしにくく、H2 の中にある「内訳」にも見えなかった。
- 線は作者が引く区切り線（`---`）と見分けがつかず、行ごとに独立したセクションに見えていた。
- サイトでは枠線を使わない。面の塗りと余白で分ける。

## Decision
- すべての `mediaRow` をカードにする。隣り合う（間に空白しかない）同じ種類の `mediaRow` は1枚のカードにまとめ、1手順ずつ切り替えて見せる。1つだけのものは1手順のカードにする。
- カードの種類とラベル：
  - `Deep dive`：workflow JSON を持たない行（上の workflow の内訳）。読み飛ばしてよい寄り道なので、この種類だけアクセント色（紫）を使う。アイコンは虫めがね。
  - `Workflows`：行に workflow JSON がある（作例やモード別の例）。灰色。アイコンはノードのつながり。
  - `Walkthrough`：Notes の記事。灰色。アイコンは地図。
- カードの構成（上から）：ヘッダー（左上の角が種類の色の四角、ラベル、直前の見出し名）→ 手順バー（手順名つき、押すとその手順へ）→ 画像枠 → 解説（workflow ファイル行、手順名、本文）→ 前後ボタン（隣の手順名つき、カード幅の半分ずつ）。
- カードの高さは切り替えで変わらない（CLS を出さない）。
  - 画像枠の比率は、そのカードの画像の縦横比の中央値をビルド時に決める（1.2〜2.4、上限の高さ 24rem）。画像は枠に収まる最大の大きさで中央に置く。
  - 解説欄はそのカードで一番長い解説の高さ。中でスクロールさせない。
- 操作：手順バー、前後ボタン、画像から下のカード左右の領域（ホバーで端が暗くなり矢印が出る）、スマホの横スワイプ、画面に見えているカードへの ← → キー。
- 画像はカードの面と色が近いため、カード内の画像だけ柔らかい影で浮かせる（本文の画像は平らなまま）。
- カード内の workflow ファイル行とコードはカードの面より一段明るい塗りにする。黒く沈めない。
- `mediaRow` の `align` と `width` は受け付けるが使わない。`mediaFooter` の中身は画像の下ではなく、解説の先頭に置く。

## Consequences
- 記事の書き換えは不要。見出し名・手順名・種類はビルド時に自動で決まる。
- 手順ごとの解説の長さに差があると、短い手順の下に空きが出る。長すぎる手順は記事側で短くする（例：resize-crop-pad の scale total pixels の表を2例に減らした）。
- 見えていない手順の文字はページ内検索に掛からない。

## Revision (2026-09-30): スライドをやめて一覧に戻す
- 読み物として操作を増やさないことを優先し、1手順ずつ切り替えるスライドをやめた。手順バー、前後ボタン、左右の領域、スワイプ、矢印キー、高さの固定、`src/assets/js/media-steps.js` は削除。
- 各手順を1枚ずつ浮いたカードにし、カードの間に小さな隙間を空けて縦に並べる。種類のヘッダーは最初のカードだけに付ける。
- カードの中は画像（約4割、上下中央）と解説の横並び。スマホでは縦並び。解説は本文より一回り小さく、色も一段落とす。手順名は太字の段落か見出しから取り、見出しでも TOC には出さない。
- 画像が小さくて読めない問題は拡大表示で補う。拡大表示（`src/assets/js/lightbox.js`）を作り直した：
  - ステップカードの画像は、中央に浮くウィンドウで開き、右に手順の解説を出す。拡大はウィンドウの中だけ。
  - それ以外の画像・動画は枠なしで浮かべ、最初はウィンドウと同じくらいの大きさ、拡大すると画面いっぱいに広がる（元の四角で切り取らない）。
  - ページ内のすべての画像・動画を ← → と前後ボタンで順に回れる。前後ボタンはウィンドウのすぐ外、閉じるボタンと拡大操作は画面の隅で、どの表示でも同じ位置。
  - 動画も拡大・移動できる（拡大中は再生バーを隠し、スペースで再生・停止）。拡大表示中の ← → は、動画にフォーカスがあっても次の画像へ進む。
- 空き（高さ固定で出ていたもの）と、見えていない手順がページ内検索に掛からない問題は、一覧に戻したことで解消した。
