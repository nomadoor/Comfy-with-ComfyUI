# ADR: Add Multiple ComfyUI Instances Column

Date: 2026-05-24

## Status

Accepted

## Context

The owner wants a beginner-facing article explaining that ComfyUI can be launched multiple times, but each running server needs a separate port. The topic is an operational ComfyUI usage pattern rather than a workflow recipe, AI capability, or troubleshooting-only note.

The owner also identified a related future topic: opening ComfyUI in multiple browser tabs.

## Decision

Add `ComfyUIを多重起動する` under `begin-with` > `コラム`.

Use slug `multiple-comfyui-instances`.

Record `ComfyUIを複数タブで開く` as a hidden draft backlog item for `begin-with` columns.

## Consequences

The new page appears in JA/EN/ZH navigation after the owner explicitly requested translation work.

The article can link to the existing `コマンドライン引数` page for `--port` details instead of duplicating the full argument list.
