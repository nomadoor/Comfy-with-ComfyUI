# ADR: 注意書きを種類で分け、`>` を引用に戻す (2026-09-29)

## Status
Accepted（振り分けの一覧はオーナー確認後に適用）

## Context
- 記事の `>` は、注意・補足・ヒント・本当の引用（プロンプト例、画像、発言）がすべて同じ見た目（紫の塗り＋情報アイコン）になっていた。日本語記事に119個。
- 本当に危ない注意（データが消える、課金が始まる、クラッシュする）が余談と同じ強さで埋もれ、ただの引用やプロンプト例まで注意書きに見えていた。
- 紫の塗りは、数の多い補足にまで使われているため目立ちすぎていた。

## Decision
- GitHub と同じ書き方で注意書きを3種類に分ける。1行目にマーカーを書く。
  - `> [!NOTE]` 補足・余談。一番多く、一番静か：カードと同じ薄い塗り（本文色 6%）、灰色の情報アイコン。
  - `> [!TIP]` ヒント・案内（先に読むページ、応用、おすすめの使い方）：弱めた紫の塗りと電球アイコン。
  - `> [!WARNING]` 注意（データ消失、課金、クラッシュ、ライセンス、ハマりどころ）：琥珀色（News の ai-capabilities の点で使っている既存の `#c98a32`）の塗りと警告アイコン。ここだけははっきり目立たせる。
- マーカーのない `>` は本当の引用：塗りもアイコンも付けず、字下げと控えめな文字色だけ。プロンプト例、発言、画像や動画を囲んだもの、キャプション。
- IMPORTANT と CAUTION は区別がつきにくいため使わない（書かれた場合は WARNING として扱う）。
- 枠線は使わない。

## Consequences
- 既存の `>` は種類を振り分けて書き換える。日本語・英語・中国語とも同じ振り分け（オーナーの指示で全言語に適用）。
- 見出しラベル（Note など）は表示しない。アイコンと色で区別する。
