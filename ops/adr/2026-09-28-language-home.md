# ADR: 言語トップページ（/ja/ /en/ /zh/）を追加する (2026-09-28)

## Status
Accepted

## Context
- `/` は「このサイトの使い方」へ302転送されるだけで、`/ja/` `/en/` `/zh/` はいずれも404だった。
- サイトの入口として、何のサイトかを一言で伝え、実際に使うモデルへすぐ案内できるページがない。
- セクション一覧ページは、サイドバーのセクションタブがページ遷移しないため、作ってもサイト内から辿れない。

## Decision
- 日本語の言語トップ `/ja/` を追加する（`src/content/ja/home.njk`、slug `home`）。
- 構成は次の順とし、各セクションの間に区切り線を入れる。
  1. 「ようこそ！Comfyに使うComfyUIへ」：オーナー自身の文章でサイトの目的を伝える（「このサイトの使い方」から移したもの）。
  2. 「2026年◯月のおすすめモデル」：性能・汎用性・安定性が高く、今ならとりあえず使っておけばよいモデルを、用途（画像生成／画像編集／動画生成）ごとの小見出しの下に、記事のサムネイル付きカードで紹介する。動画の記事はカード内で動画を再生する。frontmatterの `picks.groups`（`label` と `items[{page, text}]`）で管理する。初回はオーナー指定の Krea 2 / Anima（画像生成）、Qwen-Image-2.1（画像編集）、MiniMax H3（動画生成）。
  3. 「最近の更新」：各言語の `news.md` の先頭5件を自動で表示する。
  4. 「このサイトを作った人」：名前とX / GitHub / Redditのアイコン、オーナーの文章、問い合わせ先（お問い合わせページとX）。
  5. 「ライセンス」：CC0。
- セクションの入口一覧は載せない。セクション一覧ページは作らず保留する（画面のパンくずを作る際に再検討する）。
- `/` は `/ja/` へ301で転送する。
- `/en/` `/zh/` も同じ構成で用意する（2026-09-29、オーナー承認）。
- 「このサイトの使い方」ページはURL・内容とも残すが、全言語のナビから外す（トップが入口を兼ねるため）。最終的な扱いは「はじめてのComfyUI」セクションをチュートリアル型に再構成する際に決める。
- ヘッダーのロゴとフッターの先頭リンク（トップ / Home / 首页）は言語トップへリンクする。

- 404ページは言語ごとに用意する（`/404.html` は日本語、`/en/404.html` `/zh/404.html`）。Cloudflare Pagesは最も近い404.htmlを返すため、英語・中国語のURLではその言語の404になる。404ページには修正報告リンクを出さない。

## Consequences
- 「はじめてのComfyUI」の再構成（上から順に読むとインストールから作品制作、リーダブルノードまで身につくチュートリアル構造）は別の作業として予定している。その際にトップの内容も見直す。
- おすすめモデルは月単位で見直す前提で、見出しに年月を含める。入れ替えたときは `updated` も更新する（sitemapの`lastmod`に使われる）。`picks` のURLは `npm run check` で存在を検証する。
- 言語メニューは各ページの実URLから翻訳先を作り、その言語のページがビルドされていない場合は「このサイトの使い方」へ案内する（noindexのページも存在するページとして扱う）。router遷移後は取得したページのメニューのリンクをそのまま使う。
